# Multiple-line editing

Open **Windows → Multiple lines**, enable **Edit multiple lines**, and choose
**Notes** or **Events / Storyboard**. The second option applies to the current
right-hand workspace. Switch that workspace to Storyboard to edit extended
RPE events in side-by-side source-line columns.

Notes can also use an overlay. Events and Storyboard use separate columns with
horizontal scrolling, adjustable column width, and shared chart time/zoom.
Outer column boundaries use the same theme color and stroke as note columns.

Pressing a column focuses its source line. New events are created in that line;
existing events retain their source IDs when selected, moved, resized, copied,
pasted or erased. Box selection and group edits can span columns. Select all,
invert and Storyboard range selection operate on the configured source-line
list. Complete gestures share the editor's Undo/Redo and cancellation behavior.
View settings are saved through the existing multi-line preferences and do not
change chart data or export formats.
